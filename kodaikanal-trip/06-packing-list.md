# Packing List

Kodaikanal in Oct–Dec: **10–18°C**, rainy and foggy. Nights are cold.

## For guests (send this on WhatsApp)

**Clothes**
- [ ] Warm jacket / sweater (must)
- [ ] Cap / beanie, gloves (optional)
- [ ] 2 sets of comfortable clothes + night wear
- [ ] Raincoat or umbrella (must in Oct–Dec)
- [ ] Sports shoes with good grip (for Dolphin's Nose trek) – no slippers on the trek
- [ ] Slippers/floaters for stay
- [ ] Extra pair of socks (wet shoes happen)

**Documents**
- [ ] **Original ID proof** (Aadhaar / DL) – needed at hotel check-in
- [ ] Some cash + UPI

**Personal**
- [ ] Reusable steel water bottle (plastic is banned in Kodai)
- [ ] Toiletries, towel
- [ ] Personal medicines
- [ ] Motion-sickness tablets if you get ghat sickness
- [ ] Power bank + charger
- [ ] Neck pillow + small blanket/shawl for the night journey
- [ ] Moisturizer / lip balm (cold, dry air)
- [ ] Small backpack for the day

**Don't bring**
- Plastic bottles/covers, alcohol in the TT, expensive jewellery, big suitcases (TT luggage space is limited – 1 bag + 1 backpack per person)

## Guide kit (YOU must carry)
- [ ] Printed + phone copy of: guest list with phone & emergency contacts, TT permit, e-pass QR, hotel booking confirmation
- [ ] **First-aid kit:** band-aids, cotton, Betadine, Dolo 650 / Paracetamol, Avomine (motion sickness), ORS, Digene/Eno, Cetirizine (allergy), Volini spray, crepe bandage, Vicks, Strepsils, sanitizer
- [ ] **Cash ₹5,000** (tolls, parking, emergency)
- [ ] Power bank (20,000 mAh) + multi-pin charger + extension box
- [ ] Torch / headlamp (Dolphin's Nose early morning, power cuts)
- [ ] Whistle (to gather the group)
- [ ] Garbage bags for TT
- [ ] Tissue rolls, wet wipes
- [ ] 20 L water can in TT + paper/steel cups
- [ ] Night snack packs
- [ ] Bluetooth speaker / games (cards, dumb charades list) for bonfire
- [ ] Pen + small notebook (expense tracking)
- [ ] Spare umbrella / raincoat
- [ ] Rope / bungee cords (luggage carrier on TT roof, if used – cover with tarpaulin in rain)
